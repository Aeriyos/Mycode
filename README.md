# Inventory Management System

## Description
A comprehensive Inventory Management System built with Python and SQLite. This application allows users to manage product inventory, track purchases, update stock levels, and maintain a purchase history.

## Features
- **Add Products**: Add new items to the inventory with details
- **Update Products**: Modify existing product information and prices
- **List Products**: View all products currently in inventory
- **Purchase Products**: Buy items and automatically update stock levels
- **Purchase History**: Track all purchases made through the system
- **Database Management**: SQLite database for persistent storage
